### 6. Second-connect ground truth (the VP-W1 fence, what the code can honestly promise)

"Proven-dead" on a unix socket today can honestly mean exactly one thing: **the server-side read loop for that channel has exited** — peer closed / process died ⇒ `scanner.Scan()` returns false ⇒ `run()` returns ⇒ the conn is deleted from `s.clients` and closed (server.go:181-201). Kernel close-detection is reliable for process death (fd release).
