The validator selects only exact `m3.app_event.v1|v2` literals, rejects unknown
or duplicate fields, applies the complete fixed/required/conditional rules,
checks canonical counters and RFC3339 timestamps, and preserves v2's optional
frozen-core digest without inferring pipeline state. The exact received bytes
are stored only after validation. An exact event-id replay is idempotent; a
different body at the same identity fails closed and the first row stands.
Malformed events create no row, so the persistence path has no silent-drop
success branch.
