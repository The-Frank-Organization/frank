### 4. Claim-boundary probes (answered from locked text only)

(a) **"Durable FIFO — exactly-once":** the locked claim is **"at-least-once intake, exactly-once EFFECT, zero stale re-emission"** (m-7 §2.2 :58). Power loss may drop a not-yet-fsynced command (the seat retries; content-hash dedupes the retry — :57), so intake is NOT exactly-once. The honest G2 gate wording: order preserved = journal arrival order; exactly-once = exactly-once OUTCOME/effect (re-enqueue set = intake−outcomes; an outcome'd entry can never re-emit). S2 fixtures and docs must say "exactly-once effect," never "exactly-once delivery of every submitted command."
(b) **GC "never drops a live record":** locked posture is STRONGER — canonical records are never GC'd AT ALL, live or not (retain-everything, m-7 §10 :137). The GC target set from locked text = {old rendered projections; drained intake/redo journal segments whose entries all have outcomes}. Note: disp :38 says "garbage-collection of superseded/consumed **records**" — read through §10, "records" there can only mean derived artifacts + drained segments; the ROADMAP :11 already says "derived artifacts" correctly. For journal segments, "live" = any entry without an outcome ⇒ its segment is not drained ⇒ not collectable. The S2 gate fixture should assert both: (i) records/ byte-untouched by GC, (ii) no outcome-less entry ever in a collected segment.
(c) **Materialize-first honesty:** the projection guards RECORDED owed-items only — `open = owed-record with no disposition-record` is computed over committed records; an obligation nobody committed is invisible to it. It does NOT make an unrecorded observation impossible to miss (disp :39, VP watchpoint verbatim). Every projection-adjacent claim in S2 code/docs carries this + the standing frame: provenance + transport, not verified work; "done" = self_reported; tool-mediated confusion-resistance; D5 shell-routed-confusion residual beside every exclusivity-shaped claim (disp :55-56; ARCH C4.3 :461).
