**HONEST LABEL (label == mechanism — the domain's own rule):** `find-references` proves a **lexical, boundary-delimited token count over the declared textual domain** — **NOT a semantic reference analysis** (a match inside a comment or string literal counts; an aliased/indirect reference does not). `count:0` is a **lexical-absence** signal, never "no references exist." *(The same discipline as differential ≠ semantic proof.)*
