## Scope (owns)
- **The model-turn / session / context state machine** — one lane, one turn: assemble the request, call the adapter (m-8), consume the normalized stream, manage context/session state across turns.
- **Governed *requests* to tool execution** — m-9 parses tool calls from model output and *requests* execution; **a parsed tool call stays INERT until the existing trusted authority/tool-exposure path authorizes it** (kickoff §2). The observe-gate applies to model output; the authority-ceiling is enforced BEFORE any tool runs.

## Boundaries (does NOT own)
- **m-7's substrate** — process/concurrency, the single-threaded serialized commit loop, crash-atomic commit + recovery, trusted config load + integrity, the seat interface-guardrail. m-9 runs *on* m-7; it does not re-own any of it.
- **m-5's authority ceiling** — m-9 requests within the ceiling; it does not set or enforce it.
- **Credentials · endpoints · egress · routing** — m-7/m-3/m-4 own those. m-9 never handles a secret or selects a provider; it drives the lane it is handed.

## Consumer-lock seams (interface-lock-first; Master+VP lock the joins)

- **m-9↔m-7** — the host substrate boundary (the runtime loop sits *on* m-7's process/commit loop, does not reimplement it); the provider-request-egress point on the send path.
