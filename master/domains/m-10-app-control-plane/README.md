## Engagement
The **app control plane / supervisor** — the local hub of the bundled app (modular monolith + supervised workers over local IPC, **not** networked microservices). It **hosts and sequences**; it owns **no policy**. Design-lead `.planner` + adversarial design-reviewer `.implementer`, independent operator-relayed sessions.

## Scope (owns)
- **Worker lifecycle + supervision** — spawn/restart/terminate the app-side workers (m-9 runtime), the **one-active-worker / active-turn lease** invariant (distinct from m-9's one-active-turn invariant).
- **App-side IPC + backpressure** — the framed local transport between the control plane, workers, and the connector (NOT the conductor's `submit`/`project`/`read`).
- **Run/session-state persistence orchestration** — the app **run manifest** (the pinned-lane MVP run state: immutable m-8 lane ID + catalog digest — **not** an m-4 routing decision) + run/supervisor state, its own store + writer.
- **The app scheduler** — worker scheduling, provider-await, run cancellation, backpressure — distinct from the conductor governance-gate park/wake/ODB (m-6); bridged to it only by the worker seat's existing conductor verbs.
- **The app-side authority ENFORCEMENT POINT** — enforces the **m-5-authored ceiling artifact** for m-9 tool dispatch (reads it, binds it to `run_id` + worker identity, **fails closed when absent/stale**). m-10 **does NOT own** the ceiling policy.
- **Connector supervision + opaque credential-reference orchestration** — supervises the m-8 connector; passes **opaque credential references only, never secret bytes** (secrets live in m-8 under m-1's boundary).

## Boundaries (does NOT own — hosts + sequences, owns no policy)
- **No policy**: not m-3 egress, m-4 routing, m-5 archetypes/ceilings, m-6 human-governance, m-8 provider wire, m-9 turn state.
- **Not a conductor seat / not a stamped participant** — m-10 holds **no `submit` credential**; it supervises without authoring as the worker. A conductor relay about a run is submitted by the **m-9 worker seat**, not m-10.
- **No credentials/secret bytes** — m-1 governs the secret boundary; m-8 is the runtime holder; m-10 orchestrates opaque references only.
- **Not the conductor** — the conductor is its own isolated service; m-10 does not re-own its store/commit-loop/gates.
