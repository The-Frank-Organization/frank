## §1 — Item C: the env sanitization rule

The frozen substrate: hardening #1 (sanitized env) + #7 (allow-list, not deny-list). The rule, exact:

1. **Construct-from-empty, never inherit-then-filter.** The presented child environment is BUILT from the empty set. A filter over the inherited parent env is non-compliant (deny-lists fail open on unknown names).
2. **TWO positive classes + deny-all (F4):**
   - **Class (i) — the POSIX execution baseline, enumerated EXACTLY (no wildcards), each with a PINNED source + value constraint:**
     | var | source (never ambient inheritance) | value constraint |
     |---|---|---|
     | `PATH` | fixed approved toolchain directory list (build/config constant) | must not contain the private runtime dir, the credential-sink parent, or any workspace root |
     | `HOME` | a **dedicated empty tool-home directory**, created per run (0700) | NOT the real user home — ambient default-credential discovery (`~/.aws`, `~/.config`, …) is absent **at the env grain** |
     | `TMPDIR` | a dedicated per-run tool-tmp directory (0700) | distinct from the control/private runtime dir and every workspace root |
     | `LANG`, `LC_ALL` | the constant `C.UTF-8` (exactly these two locale vars; no `LC_*` family) | fixed |
     | `TZ` | the constant `UTC` (pinned for this MVP; a future operator-selected timezone routes through an owned surface — R2-F1) | fixed |
     | `TERM` | `dumb` | fixed |
     | `SHELL` | the resolved `shell_interpreter_ref.path` | consistency with the descriptor |
     | `USER`, `LOGNAME` | the process user name (an OS fact) | non-secret identity string |
     | `PWD` | **the ABSOLUTE, symlink-resolved EXECUTION cwd** — obtained by resolving the descriptor's relative F103 `cwd` under the selected workspace root (R2-F1: `PWD` states the process working directory; the DESCRIPTOR keeps its one relative encoding — two facts, each true in its own encoding, never conflated) | must equal `/bin/pwd -P` in the child |
   - **Class (ii) — EMPTY for this MVP (F4).** The frozen m-10 manifest carries no environment member and no released owner contract exists for one; this delta assigns no new producer surface. If a future step needs operator-selected run env vars, that is a **master-routed manifest schema addition to m-10** consumed here by amendment — never an m-1-invented carrier.
   - **Everything else is ABSENT** — every operator ambient provider credential (#7), every `FRANK_*`/broker/connector/m-10 control variable, every var naming a secret-sink or private-runtime path.
3. **Honest grain (F4):** with the dedicated `HOME`/`TMPDIR` + fixed `PATH`, ambient credential discovery is structurally absent **at the environment grain only** — a same-UID `bash` can still reach the real home or any file by absolute path (the frozen §1.2 unsandboxed residual, unchanged; H-12 is the OS boundary).

## §2 — Item D: the redaction boundary, the at-rest file, and the K6 exclusion

1. **The claim, SPLIT (F1 — structural where structure exists; honest ceiling where content is open):**

2. **The "NOT in the log" contract — the closed families (F2):**
