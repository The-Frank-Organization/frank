**MR-3 — the Go map-aliasing bypass (verified, fixed).** Confirmed at source: `record.Record.Headers`/`XFields` are maps (`record.go:29,31`); `migrate.Apply` shares them via the shallow `out := rec` (`migrate.go:64`); the canonical migrator mutates `rec.Headers` in place (`migrate_test.go:31-32` — `rec.Headers["new"]=…; delete(rec.Headers,"old")`). So an in-place choice migrator replacing `Headers["choices"]` mutates the **shared** map ⇒ both "source" and "migrated" expose the changed choices ⇒ `π(source)==π(migrated)` **bypasses the guard**, and because `classifyVerdict` reads source from `t.Records`, the same alias **corrupts the live table view** during classification. No existing record deep-clone helper (`git grep` = none).

**The fix (§2.2 executable order, now alias-safe):**
1. Key on immutable **source** ODB identity (unchanged).
2. **Snapshot `π(source)` BEFORE any migrator runs** — parse the stored `choices` and capture `π(source)` as a **value** (a copy of the `{value→label}` pairs, never a reference into `Headers`), before calling `Apply`. This is the invariant's left operand; a later migrator cannot mutate it.
3. **Deep-clone at the migrator boundary — the ownership locus = `migrate.Apply`.** `Apply` deep-clones the record (Headers + XFields) before invoking each migrator step. I chose `Apply` (not just `classifyVerdict`) because it is m-2's read-side migration seam (§9) and the fix then protects **every** caller — the `read` tool, replay, and the verdict path — and prevents any migrator from aliasing the caller's source or the live `t.Records[odb]` view. Named s11 hardening of `Apply`, not extant.
4. Obtain the guarded migrated view via `migrate.Apply(reg, source)` (deep-cloned); the raw `t.Records[odb]` read is replaced.
5. **Compare the pre-Apply snapshot vs `π(migrated)`** (left operand = the step-2 snapshot, not a re-parse of a possibly-aliased record); either-side parse **fail-closed**.
6. Validate pick against the migrated view (unchanged).
7. Any failure → the typed incompatibility signal (§2.3).

**Fixture (§2.5):** `NF-migrate-choice-inplace-mutate` — an in-place mutating migrator (matching the `migrate_test.go:31-32` style) that replaces `Headers["choices"]`; asserts (a) the guard **fires** (the pre-Apply snapshot is unaffected, so `π(source-snapshot) ≠ π(migrated)`), (b) the raw source/table record is **byte-equivalent in memory** (the deep-clone isolates the migrator — `t.Records[odb]` untouched) **and on disk**.
