### Work item 1 — the close-once race (production)

**The defect, code-verified at `2e1b4f0` this session:** `Client.Close` and `Client.readLoop`'s deferred cleanup each run `select { case <-c.done: default: close(c.done) }` — an unsynchronized check-then-act; two concurrent closers (reconnect kills the conn → readLoop exits, while the shim calls `Close`) can both take the `default` arm and both `close`: the proven production double-close panic (VP: red once through `Close`, once through `readLoop`).

**Locked mechanism (my design, the one-close-owner shape):**
1. `Client` gains `closeOnce sync.Once`; ONE new unexported method is THE close owner:
   `func (c *Client) closeDone() { c.closeOnce.Do(func() { close(c.done) }) }`
2. `Client.Close()` becomes `c.closeDone(); return c.conn.Close()` — the select/default idiom is **removed**, not guarded.
3. `readLoop`'s defer becomes `defer c.closeDone()` — idiom removed there too.
4. **Same-class latent site, same primitive (in-fence, severable):** `Server.Close` carries the identical idiom on `s.done`. Today it has a single closer, but `Close` is exported and double-callable — apply `s.closeOnce` + `s.closeDone()` identically. If your plan-review objects to the widening, this leg severs cleanly without touching the item-1 acceptance; my default is IN (same file, same defect class, ~6 lines, and it spares the next reviewer the same finding).
5. **New named regression test** in `internal/channel`: `TestClientCloseIdempotentUnderRace` — N (≥100) iterations of {connect a Client, then concurrently: kill the server-side conn (driving readLoop exit) + call `Close()` from a second goroutine + a third `Close()`}; run under `-race`. Small, focused, permanent.

**File/function targets:** `internal/channel/server.go` — `Client` struct (~`:424`), `Client.Close` (`:519-525`), `readLoop`'s defer (`:555-562`), `Server` struct + `Server.Close` (`:216-220`, the severable leg); one new test file or an addition to the existing channel lifecycle tests.

**Acceptance (master-pinned — the VP's shape, restated binding, not tradeable):**
